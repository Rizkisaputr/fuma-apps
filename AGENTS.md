# FUMA Apps

- Proyek menggunakan Laravel 13 dan MySQL.
- Antarmuka akan dibuat dengan Blade dan Livewire 4.
- Periksa struktur proyek dan perubahan Git sebelum mengedit file.
- Jangan memasang Laravel Boost atau menambahkan MCP tanpa permintaan pengguna.
- Jangan menjalankan git add, commit, atau push kecuali diminta pengguna.
- Jangan mengubah atau mengunggah file .env.
- Untuk sesi badminton gunakan tabel play_sessions; tabel sessions bawaan Laravel dipakai untuk sesi login.
